# 快团团海报生成器

纯前端、零依赖的快团团商品海报生成工具。左侧填写商品信息，右侧实时预览，一键导出 720×1280 竖版海报 PNG。全部处理在浏览器本地完成，**不上传任何数据到服务器**。

## 功能

- **3 套版式模板**：居中促销（红）/ 左图清单（青）/ 大图爆款（橙），一键切换实时重绘
- **完整字段编辑**：顶部标签、团长昵称、商品标题（自动换行截断）、副标题、核心卖点（1-6 条增删）、原价/团购价（自动计算立省金额）、团长说、规格发货、按钮文案
- **图片处理**：商品主图 + 二维码上传；展示比例（自动识别 / 3:4 / 1:1 / 原图比例）× 适配方式（完整展示 / 铺满裁切）；「完整展示」模式自动用模糊原图做底衬避免白边
- **单张导出**：Canvas 离屏重绘导出 720×1280 PNG
- **批量生成**：粘贴多行商品数据（`|` 分隔 9 列）→ 自动识别跳过表头 → 批量渲染 → 打包 ZIP 下载
- **批量主图**：选择多张图片按顺序分配给各商品；未填写的字段自动用左侧表单当前值兜底

## 使用方法

1. 下载 `快团团海报生成器.html`（单个文件，约 43KB）
2. 双击用浏览器打开（推荐 Chrome / Edge）
3. 单张模式：直接在左侧编辑，点「导出 PNG」
4. 批量模式：滚动到底部「批量生成」，粘贴数据，点「解析数据」→「批量导出」

### 批量数据格式

每行一个商品，字段用 `|` 分隔，顺序如下：

```
团长昵称 | 商品标题 | 副标题 | 卖点1；卖点2；卖点3 | 原价 | 团购价 | 团长说 | 规格发货 | 顶部标签
```

示例：

```
小美优选 | 阿克苏苹果 5斤装 | 现摘现发 | 产地直发；爆汁甜 | 39.9 | 19.9 | 真的甜！ | 5斤/箱 包邮 | 今日开团
```

- 卖点之间用 `；`（分号）分隔，最多 6 条
- 首行为列名时会自动识别并跳过
- 任何字段留空则使用左侧表单当前值

## 技术实现

- 单文件 HTML，无构建、无框架、无外部依赖
- Canvas 2D 手绘海报（非 DOM 截图），文字逐字符测宽换行 + 省略号
- `renderToken` 令牌防止异步图片加载导致的渲染竞态
- 内置 store 模式 ZIP 打包（自实现 CRC32 + ZIP 结构），无需引入 JSZip 等库
